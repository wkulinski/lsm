# Task completion checks
- For normal code changes, run targeted Vitest tests plus `npm run typecheck` and `npm run lint:js` as appropriate; implementation skill requires `review-quick` and a focused test/lint rather than full QA unless explicitly requested.
- Full repository QA commands available: `npm test`, `npm run test:coverage`, `npm run test:typecheck`, `npm run typecheck`, `npm run lint:js`, `npm run build`, `npm audit --omit=dev`, `npm pack --dry-run`.
- Before claiming completion, report exact commands and outcomes; do not claim checks not run.
